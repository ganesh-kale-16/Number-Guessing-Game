# 🎯 Number Guessing Game

A simple **Number Guessing Game** built using **HTML, CSS, and JavaScript**.

The computer generates a random number between **1 and 100**, and the player tries to guess the number. After every guess, the game tells the player whether the guess is **too high**, **too low**, or **correct**.

## 🚀 Features

- 🎲 Generates a random number between 1 and 100
- 🔢 Allows the user to enter a guess
- ⬆️ Shows "Too High" when the guess is greater than the target
- ⬇️ Shows "Too Low" when the guess is smaller than the target
- 🎉 Shows a success message when the correct number is guessed
- 📊 Counts the number of attempts
- 🔄 Restart button to start a new game
- 📱 Simple and responsive interface

## 🎮 How to Play

1. Open the game in your browser.
2. Enter a number between **1 and 100**.
3. Click the **Guess** button.
4. Check the result:
   - **Too High** → Your number is greater than the target.
   - **Too Low** → Your number is smaller than the target.
   - **Correct** → You guessed the number!
5. Click **Restart** to start a new game.
